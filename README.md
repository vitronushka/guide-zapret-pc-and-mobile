# Обход блокировок без VPN-сервера и без денег

**Твой случай:** блокировки в РФ, всё железо дома в РФ, платить не хочется, нужны телефон + компьютер.

**Главный вывод: зарубежный сервер тебе не нужен, и VPN в классическом смысле — тоже.**

Большая часть российских блокировок (YouTube, Discord, куча сайтов) сделана через **DPI** — оборудование провайдера
смотрит на имя сайта в начале соединения (SNI / QUIC Initial) и рвёт или замедляет соединение. Сам сайт при этом
жив и доступен. Значит, не нужно ничего никуда переносить — достаточно **испортить DPI картинку пакета**:
разбить handshake на части, отправить «обманку» с неправильным TTL, поменять порядок пакетов.
Это делается **локально на твоём устройстве**, бесплатно, без серверов и без подписок.

Инструменты: `zapret` / `nfqws` (Windows, Linux, роутеры) и `ByeDPI` (Android).

---

## Что этот способ может и чего не может

| | |
|---|---|
| ✅ Работает | сайты, заблокированные по DPI/SNI; замедление YouTube; Discord (веб + голос) |
| ✅ Цена | 0 ₽, навсегда, без регистрации и лимитов трафика |
| ✅ Скорость | как без обхода — трафик не идёт через посредника |
| ✅ Приватность | трафик никуда не отправляется, всё обрабатывается на устройстве |
| ❌ Не скрывает IP | ты остаёшься со своим российским IP |
| ❌ Не шифрует | шифрование остаётся только штатное HTTPS |
| ❌ Не поможет | если ресурс заблокирован **по IP** или доступен только из-за рубежа (часть Netflix/Spotify, зарубежные банки) |
| ⚠️ Требует ухода | стратегии со временем перестают работать — раз в несколько недель/месяцев надо перепроверять |

Если тебе нужен именно «другой IP» и доступ к сервисам, которые пускают только иностранцев — это уже другой инструмент,
см. раздел [Когда всё-таки нужен настоящий VPN](#когда-всё-таки-нужен-настоящий-vpn).

## ⚠️ Сначала безопасность: тут реально много вредоносов

Тема популярная, поэтому вокруг неё кормятся мошенники. Проверенные правила:

1. **Качай только с официальных страниц GitHub Releases**, ссылки ниже. Не из Telegram-каналов, не из «сборок с GUI»,
   не по первой ссылке поисковика. В README оригинального проекта прямо предупреждают: **Яндекс-поиск часто выдаёт
   вредоносы первыми ссылками, а настоящий репозиторий прячет.**
2. **Не ставь «Zapret 2 GUI» (`github.com/youtubediscord/zapret`, автор censorliber).** В марте 2026 вышел
   [разбор на Хабре](https://habr.com/ru/articles/1015380/): форк отключает Windows Defender через реестр,
   скрытно ставит **свой корневой сертификат** (это готовая позиция для чтения твоего HTTPS-трафика и кражи сессий),
   каждые 30 минут сливает данные о ПК в приватный Telegram-чат, а EXE-сборки не соответствуют коду на GitHub.
   Песочницы ANY.RUN и Tria.ge дали вердикт **Malicious (Loader / Spyware)**. Сверху ещё и продают «premium».
3. **Для обхода DPI не нужны ни корневые сертификаты, ни отключение антивируса.** Если программа их просит — это красный флаг.
4. Реакция антивируса на файл **WinDivert** — это нормально и ожидаемо (детект называется `WinDivert` или
   `Not-a-virus:RiskTool.Multi.WinDivert`). Это легальный драйвер перехвата пакетов. Лечится **добавлением папки
   в исключения**, а не отключением защиты целиком.
5. У Flowseal **нет** никаких Telegram-каналов и YouTube-каналов. Всё, что от его имени вне его GitHub — фейк.

## Шаг 0. DNS — без этого часто «ничего не работает»

Провайдер может подменять ответы DNS, и тогда обход бессмысленно тестировать. Включи шифрованный DNS:

- **Windows 11:** Параметры → Сеть и Интернет → своя сеть → Назначение DNS-сервера → Изменить → вручную →
  DNS через HTTPS (DoH) → включить, сервер `8.8.8.8` (шаблон `https://dns.google/dns-query`).
- **Chrome:** Настройки → Конфиденциальность и безопасность → Использовать безопасный DNS → выбрать поставщика
  **не** «по умолчанию». **Firefox:** DNS через HTTPS → «Персональный» → `https://dns.google/dns-query`.
  Cloudflare (`1.1.1.1`) в РФ местами заблокирован, поэтому Google DNS надёжнее.
- **Android:** Настройки → Подключения → Другие настройки → **Персональный DNS-сервер** →
  имя хоста провайдера: `dns.google`.
- **Роутер Keenetic:** включи опцию **«Транзит запросов»**, иначе она ломает Secure DNS на компьютерах.

## Шаг 1. Компьютер (Windows) — 10 минут

Актуальная проверенная сборка: **[Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)**,
релиз **1.10.4 от 20.10.2026**. Бинарники внутри взяты из официального `zapret-win-bundle` от автора zapret (bol-van),
проверяется по хэшам.

### Вариант «в одну команду» (мой скрипт)

В папке `windows/` лежит `zapret-setup.bat`. Он сам скачает **последний** релиз с GitHub, снимет с архива
метку «из интернета», распакует в `C:\zapret` (путь без кириллицы — это важно) и откроет нужную папку.

1. Правый клик по `zapret-setup.bat` → **Запуск от имени администратора** (он и сам попросит права).
2. Дождись конца, откроется папка `C:\zapret`.

### Вариант руками

1. Скачай `zapret-discord-youtube-<версия>.zip` со [страницы последнего релиза](https://github.com/Flowseal/zapret-discord-youtube/releases/latest).
2. Правый клик по архиву → Свойства → галочка **«Разблокировать»** (если распаковываешь 7-Zip/PeaZip — не нужно).
3. Распакуй в путь **без кириллицы и спецсимволов**, например `C:\zapret`.

### Дальше — одинаково для обоих вариантов

4. Добавь папку `C:\zapret` в исключения антивируса (из-за WinDivert, см. выше).
5. Запусти **`service.bat` от имени администратора** → **`Run Tests`** → **`Standard tests`** → **`All configs`**.
   Это перебор стратегий: скрипт сам скажет, какие работают у твоего провайдера. **Это главный шаг — не угадывай стратегию вручную.**
6. Возьми working-стратегию и поставь на автозапуск: **`service.bat`** → **`Install Service`** → выбери её.
   Всё, дальше оно работает само после перезагрузки, окна держать открытыми не надо.

**Проверка:** открой YouTube и Discord. Если Discord «не подключается» — почисти его кэш
(`service.bat` → `Run Diagnostics`, там есть очистка кэша).

**Альтернатива, если winws не заводится:** [ByeDPIManager](https://github.com/romanvht/ByeDPIManager) v1.1.3
(обновлялся 30.10.2026) — ByeDPI + ProxiFyre под Windows, другой механизм перехвата.

## Шаг 2. Телефон (Android) — 5 минут

Ставь **[ByeByeDPI](https://github.com/romanvht/ByeByeDPI)** — живой форк (7.2k ★, релиз **v1.8.2 от 02.10.2026**).
Оригинальный `dovecoteescapee/ByeDPIAndroid` заброшен с сентября 2024, его советы из старых статей устарели.

1. Скачай APK со [страницы релизов](https://github.com/romanvht/ByeByeDPI/releases/latest):
   `ByeByeDPI-v1.8.2-universal-release.apk` (universal — если не знаешь архитектуру телефона).
   Единственный официальный сайт проекта: `https://byebyedpi.xyz` — там же инструкция от комьюнити.
2. Установи (разрешив установку из браузера/файлового менеджера). **Root не нужен.**
3. Нажми подключение, согласись на запрос Android о VPN-соединении.
4. Включи в настройках **автозапуск при старте устройства**.
5. Если что-то не открывается — меняй параметры командной строки; приложение умеет **сохранять списки параметров**,
   так что можно держать несколько стратегий и переключаться. Есть **раздельное туннелирование по приложениям** —
   удобно пускать через обход только браузер/YouTube/Discord, остальное оставить напрямую.

> Приложение использует VPN-режим Android только чтобы завернуть трафик в себя. Никуда его не отправляет,
> не шифрует и IP не меняет. Батарею почти не ест.

Работает и на **Android TV / ТВ-боксах** — совместимость в этом форке специально улучшена.

## Шаг 3. iPhone / iPad — честно: тут сложнее

Локального обхода DPI для iOS нет — Apple не даёт приложениям так работать с пакетами. Варианты:

1. **[Amnezia Free](https://amnezia.org/ru/free)** — бесплатно, без регистрации, без рекламы, безлимит.
   Ставишь приложение **AmneziaVPN** из App Store → кнопка «VPN от Amnezia» → выбрать **Amnezia Free**.
   Протокол AmneziaWG (устойчив к блокировкам). **Нюанс:** через VPN идут только заблокированные
   общественно значимые сайты из их списка (200+), остальное — напрямую с твоего IP. Нужного сайта нет в списке —
   пишут на `support@amnezia.org`. Это же приложение есть и на Android, как запасной вариант.
   Если сам сайт amnezia.org не открывается — зеркало: `https://storage.googleapis.com/amnezia/amnezia.org`.
2. **Tor** — Onion Browser / Orbot, лучше с мостами (obfs4 / Snowflake). Бесплатно и без серверов, но медленно,
   YouTube смотреть больно.
3. Настроить обход **на роутере** (шаг 4) — тогда iPhone покрывается автоматически, без приложений. Для iOS это самый удобный путь.

## Шаг 4. Всё сразу через домашнее железо (роутер / Raspberry Pi / домашний сервер)

Вот где твоё домашнее железо реально пригодится: один раз настроил — и **все устройства дома**, включая iPhone,
ТВ и приставку, получают обход без настройки каждого.

**Критично понять:** zapret обрабатывает только тот трафик, который **физически проходит через машину**.
Если поставить его на домашний ПК, который не является шлюзом, обход будет только на этом ПК. Варианты:

| Куда ставим | Комментарий |
|---|---|
| **Роутер с OpenWrt** | идеальный вариант: весь трафик дома и так идёт через него. Есть готовые сборки `zapret-vXX-openwrt-embedded.tar.gz` |
| **Роутер Keenetic** | ставится через Entware, не забудь «Транзит запросов» |
| **Raspberry Pi / домашний Linux-сервер** | нужно сделать его шлюзом: либо прописать клиентам его IP как шлюз (DHCP-опция 3 на роутере), либо включить на нём NAT. Иначе эффекта для других устройств не будет |
| **Обычный домашний ПК** | покроет только себя — тогда проще сразу шаг 1 |

Инструмент: **[bol-van/zapret](https://github.com/bol-van/zapret)**, релиз **v72.13 от 21.07.2026** — это оригинал,
на нём же основаны все Windows-сборки. Есть более новый **[zapret2](https://github.com/bol-van/zapret2) v1.0.7
(05.11.2026)** — стратегии там пишутся на Lua, гибче и мощнее, но сложнее в настройке. Для первого раза бери zapret1.

### Установка на Debian / Ubuntu / Raspberry Pi OS

В папке `linux/` лежит `install-zapret.sh`: поставит минимум для скачивания, скачает свежий релиз,
запустит **официальный `install_prereq.sh`** (он сам разберётся с зависимостями под твой дистрибутив)
и затем официальный `install_easy.sh`.

```bash
sudo bash install-zapret.sh
```

Установщик `install_easy.sh` **интерактивный**. Что отвечать по существу:

- `enable tpws transparent mode?` / `tpws socks mode?` → **нет** (это прокси-режим, не наш случай)
- `enable nfqws?` → **да**, это и есть обход DPI
- интерфейсы → внешний (`eth0`/`wlan0`); если машина будет шлюзом для дома — укажи и внутренний
- `MODE_FILTER` → `hostlist` (по списку доменов) или `autohostlist` (сам определяет заблокированные);
  `none` = обходить всё подряд, так не надо
- flow offloading → `donttouch`: аппаратное ускорение роутера ломает nfqws
- автозапуск → да

Для OpenWrt скрипт не подходит — там нужен архив `zapret-vXX-openwrt-embedded.tar.gz`,
распаковать в `/tmp` и запустить `sh /tmp/zapret/install_easy.sh`. Скрипт это определит и подскажет.


### Обязательный шаг: узнать, что именно делает твой провайдер

```bash
cd /opt/zapret
sudo ./blockcheck.sh | tee /tmp/blockcheck.txt
```

Скрипт проверит подмену DNS и переберёт техники обхода по заблокированным сайтам, а в конце выдаст
**готовые рабочие параметры**. Прогони по 2–3 разным сайтам: блокировки бывают разные, нужна техника,
которая работает на большинстве. Полученные параметры вписываются в `/opt/zapret/config`.

```bash
sudo systemctl restart zapret     # применить
sudo systemctl status zapret      # проверить
```

Полезное: свои домены — в `ipset/zapret-hosts-user.txt`, исключения (если обход ломает незаблокированный сайт) —
в `ipset/zapret-hosts-user-exclude.txt`.

## Если не работает / перестало работать

1. **Стратегии устаревают — это нормально, а не поломка.** Провайдер меняет DPI, вчерашняя стратегия умирает.
   Лечение: `service.bat` → `Check for Updates`, затем снова `Run Tests` → `All configs`.
2. Не открывается ресурс, который **без** zapret работал → `service.bat` → `IPSet Filter`, режимы `none` / `loaded` / `any`.
3. Игры и сервисы на UDP/TCP выше 1023 → `service.bat` → `Game Filter` (после переключения перезапусти стратегию).
4. Не помогло ничего → командная строка от администратора, по очереди, потом перезагрузка:
   ```
   netsh winsock reset
   netsh int ip reset all
   netsh winhttp reset proxy
   ipconfig /flushdns
   ```
5. Проверь, что стратегия реально запущена: при ручном запуске `general*.bat` в панели задач должен быть `winws.exe`.
   `service.bat` → `Check Status` покажет состояние служб.
6. Проверь DNS (шаг 0) — очень частая причина «ничего не помогает».

## Когда всё-таки нужен настоящий VPN

Локальный обход DPI не поможет, если нужно: скрыть IP, зайти в сервис, пускающий только иностранцев,
или обойти блокировку **по IP**. Тогда нужна точка за границей, и бесплатных надёжных вариантов, увы, нет:
бесплатные VPN-приложения в РФ либо заблокированы, либо живут неделю, либо торгуют твоим трафиком.

Реальные варианты, если решишь вернуться к этому:
- **Свой VPS за границей** (~3–5 $/мес, хватит 1 vCPU / 512 МБ) + **AmneziaWG** или **VLESS+Reality**.
  Ставится скриптом за 10 минут, ключ на 5 устройств, никто не отключит и не продаст твои данные.
- Бесплатные облачные тарифы (Oracle Always Free и подобные) формально существуют, но регистрация из РФ
  упирается в зарубежную карту — как правило, не вариант.

Скажи — и я соберу тебе установочный скрипт, конфиги и QR-коды под этот сценарий.
